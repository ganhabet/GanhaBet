GANHABET MOÇAMBIQUE — PROJECTO ANDROID (DEMONSTRAÇÃO)

Este pacote contém o código-fonte Android que integra o protótipo num WebView.

COMO GERAR O APK
1. Instale Android Studio num computador.
2. Extraia este ZIP e abra a pasta GanhaBet_Android no Android Studio.
3. Aguarde a sincronização Gradle e instale Android SDK Platform 35 se solicitado.
4. Escolha Build > Build Bundle(s) / APK(s) > Build APK(s).
5. O APK ficará normalmente em app/build/outputs/apk/debug/app-debug.apk.

REQUISITOS: Android Studio recente, JDK 17 e Android SDK 35.
É necessária internet na primeira sincronização do Gradle.

IMPORTANTE
Este pacote é código-fonte, NÃO um APK compilado. O ambiente desta sessão
não tem Android SDK nem Gradle para compilar o APK.
Login, perfil, jogos e saldo são apenas demonstrações locais; não há servidor,
autenticação real, depósitos, levantamentos ou apostas com dinheiro real.
